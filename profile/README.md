# 🧺 Lavanderia Colônia

## 📋 Sobre o Projeto

Sistema de gerenciamento desenvolvido para a Lavanderia Colônia como projeto da disciplina de Engenharia de Software 3 do curso de Análise e Desenvolvimento de Sistemas de Mogi das Cruzes.

O projeto visa automatizar e otimizar os processos de atendimento, controle de pedidos e gestão operacional da lavanderia, proporcionando maior eficiência e organização ao negócio.

## 🎯 Objetivos

- Digitalizar o processo de recebimento e entrega de roupas
- Controlar o fluxo de pedidos e status de serviços
- Gerenciar cadastro de clientes

## 🛠️ Tecnologias Utilizadas

- **Frontend**: []
- **Backend**: Java, Spring Boot
- **Banco de Dados**: PostgresSQL

## 🚀 Como Executar

### Pré-requisitos
```bash
Java 17
Maven
```

### Instalação
```bash

git clone https://github.com/Lavanderia-Colonia/backend

# CLone o repositório frontend
git clone https://github.com/Lavanderia-Colonia/frontend

# Acesse a pasta do backend
cd backend

# Inicie o servidor
mvn spring-boot:run

# Acesse a pasta do frontend
```
